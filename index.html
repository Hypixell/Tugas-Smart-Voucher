1. GAMBARAN PROYEK

Kamu berperan sebagai junior programmer di Teaching Factory (TeFa) bidang TKJ. Unit Mini ISP sekolah menjual voucher internet kepada warga sekolah. Petugas masih menghitung subtotal, diskon, biaya administrasi, total pembayaran, dan uang kembalian secara manual.

Tugasmu adalah membuat prototipe aplikasi kasir sederhana bernama SMART VOUCHER menggunakan HTML, CSS, dan JavaScript.

Target Pembelajaran

Proyek ini menguji pemahaman JavaScript sampai materi operasi string dan aritmatika: JavaScript internal dan eksternal, variabel, tipe data, input-output, console.log(), typeof, manipulasi string, penggabungan string, dan operator aritmatika.

Batasan Materi

Perhatian: Jangan gunakan percabangan (if/else), perulangan (for/while), atau fungsi buatan sendiri pada proyek utama. Fokuskan solusi pada materi yang telah dipelajari. Jika ada fitur yang belum pernah diajarkan, konsultasikan kepada guru sebelum digunakan.

4. FITUR WAJIB APLIKASI

A. Identitas Transaksi

Buat variabel untuk menyimpan nama pelanggan, kelas pelanggan, dan kode transaksi. Tanggal transaksi boleh ditambahkan jika materi Date sudah diperkenalkan.

B. Manipulasi String

Terapkan sekurang-kurangnya empat operasi berikut:

  • toUpperCase() untuk menampilkan nama pelanggan dengan huruf kapital.
  • toLowerCase() untuk mengubah teks jenis voucher menjadi huruf kecil.
  • trim() untuk membersihkan spasi di awal dan akhir nama.
  • length untuk menghitung jumlah karakter nama.
  • Penggabungan string untuk membuat kode atau informasi transaksi.

C. Perhitungan Transaksi

Gunakan operator penjumlahan (+), pengurangan (-), perkalian (*), dan pembagian (/) atau operasi persentase yang sesuai.

Perhatikan perbedaan operator + ketika digunakan pada string dan number.

D. Output Transaksi

Tampilkan informasi transaksi menggunakan console.log(), alert() atau elemen HTML. Gunakan template literal atau penggabungan string untuk menyusun struk.

10. PERTANYAAN REFLEKSI DAN WAWANCARA
Jawablah dengan bahasamu sendiri. Guru dapat meminta siswa menjelaskan atau menunjukkan bagian kode yang mendukung jawaban.
Karena harga voucher digunakan dalam operasi matematika seperti perkalian, pengurangan, dan perhitungan diskon. Tipe Number dapat dihitung secara langsung, sedangkan String merupakan teks.
let memiliki cakupan blok dan nilainya dapat diubah. const juga memiliki cakupan blok tetapi tidak dapat diberi nilai ulang. var memiliki cakupan fungsi dan dapat dideklarasikan ulang, sehingga penggunaannya lebih mudah menimbulkan kebingungan.
Operator perkalian (*) akan mengubah nilai numerik berbentuk String menjadi angka secara otomatis pada operasi matematika. Namun, sebaiknya input dari prompt() tetap dikonversi dengan Number() agar tipe data jelas dan konsisten.
trim() menghapus spasi di awal dan akhir teks nama sehingga nama lebih bersih, mudah dibandingkan, dan jumlah karakter dengan length menjadi lebih akurat.
toUpperCase() mengubah seluruh huruf menjadi kapital, sedangkan toLowerCase() mengubah seluruh huruf menjadi huruf kecil.
Diskon dihitung dengan rumus subtotal * 5 / 100. Contoh: 30.000 * 5 / 100 = 1.500.
Jika digunakan pada String, operator + menggabungkan teks, misalnya "10" + "20" menghasilkan "1020". Jika digunakan pada Number, operator + menjumlahkan angka, misalnya 10 + 20 menghasilkan 30.
File eksternal membuat kode HTML, CSS, dan JavaScript lebih terpisah dan terorganisasi, lebih mudah dirawat, serta dapat digunakan atau diperbarui tanpa memenuhi file HTML.
console.log() menampilkan nilai variabel dan hasil proses di Console browser. Dengan begitu, programmer dapat memeriksa alur program dan menemukan kesalahan saat debugging.
Nilai pada variabel jumlah pembelian yang digunakan dalam perhitungan harus diubah dari 3 menjadi 10. Rumus subtotal dan perhitungan berikutnya tetap sama karena hasilnya mengikuti nilai variabel tersebut.
